# Referencias de diseño

Dos `DESIGN.md` tomados de [`rohitg00/awesome-claude-design`](https://github.com/rohitg00/awesome-claude-design)
(MIT), que es una lista curada de sistemas de diseño extraídos de marcas
reales. **No es una skill instalable** — no trae `SKILL.md` ni
`.claude-plugin`: es material de referencia.

Del repositorio completo (35 archivos en 10 familias estéticas) traje solo dos,
los que calzan con el posicionamiento de Terra Volcano:

| Archivo | Familia | Por qué |
|---|---|---|
| `runway.md` | cinematic | Oscuro, dramático, premium. Es el registro de *"EXTRAORDINARY EXPEDITIONS. EXCLUSIVELY YOURS."* |
| `mercury.md` | warm | Cálido y sobrio. Más cerca de la paleta actual: obsidiana, lava, nieve |

Cada archivo trae paleta con roles, reglas tipográficas, atmósfera y
componentes. **Son referencia para decidir, no para copiar**: Terra Volcano
tiene su propia paleta en [`../brand-kit.md`](../brand-kit.md).

El repositorio completo tiene además recetas útiles que no copié —
`landing-page-20-min.md`, `brand-extraction.md`, `repo-to-design-system.md`,
`web-capture-to-prototype.md`— y paquetes de prompts como
`audit-live-site.md` y `3-designer-debate.md`. Si se necesitan, se clonan.
